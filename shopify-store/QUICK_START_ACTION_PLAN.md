## Week 1: Foundation (Days 1-7)

### Day 1: Choose Your Niche
**Time: 2 hours**

Pick a profitable niche:
- [ ] Research trending products on AliExpress
- [ ] Check competition on Shopify stores
- [ ] Ensure products are:
  - Lightweight (easy shipping)
  - $10-$40 price range
  - Not available in local stores
  - Solve a problem
  - Visually appealing

**Best Niches for Beginners:**
- Pet accessories
- Phone/tech accessories
- Home organization
- Fitness gadgets
- Beauty tools
- LED lights/decor

**Pick ONE niche to start!**

---

### Day 2: Install Dropshipping App
**Time: 1 hour**

- [ ] Log into Shopify Admin
- [ ] Go to Apps → Shopify App Store
- [ ] Search "DSers" (FREE!)
- [ ] Install DSers app
- [ ] Create DSers account
- [ ] Link AliExpress account (or create one)

**See: DROPSHIPPING_APPS_COMPARISON.md for alternatives**

---

### Day 3: Import First Products
**Time: 3 hours**

Find 10 winning products:

**On AliExpress, look for:**
- [ ] 4.5+ star rating
- [ ] 1,000+ orders
- [ ] ePacket shipping available
- [ ] Good photo reviews
- [ ] Price: $5-$25 (you'll sell for $20-$60)

**Import to DSers:**
- [ ] Copy AliExpress URL
- [ ] Add to DSers Import List
- [ ] Edit product title (make it catchy)
- [ ] Set price (2-3x supplier cost)
- [ ] Select best images
- [ ] Choose variants (colors/sizes)
- [ ] Push to Shopify

**Repeat for 10 products**

**See: PRODUCT_TEMPLATES.md for description templates**

---

### Day 4: Optimize Product Pages

- [ ] Create collections ("Best Sellers", "New Arrivals")
- [ ] Set inventory tracking

**Use templates from:**

### Day 5: Store Settings
**Time: 2 hours**

**Configure these in Shopify Admin:**

**Payments:**
- [ ] Settings → Payments
- [ ] Enable Shopify Payments (or PayPal)
- [ ] Add bank account info
- [ ] Test payment processing

**Shipping:**
- [ ] Settings → Shipping
- [ ] Create shipping zones (USA, International)
- [ ] Set rates: FREE shipping (recommended)
- [ ] Or flat rate: $4.95

**Taxes:**
- [ ] Settings → Taxes
- [ ] Enable auto-tax calculation
- [ ] Add tax ID if applicable

## Troubleshooting

### "I'm not getting any traffic!"
**Solutions:**
- Post more consistently (3-5x daily)
- Use better hashtags
- Engage more with others
- Try TikTok Reels (best organic reach)
- Consider small ad budget ($5/day)

### "I have traffic but no sales!"
**Solutions:**
- Lower your prices
- Improve product descriptions
- Better product photos
- Offer limited-time discount (20% off)
- Add urgency ("Only 5 left!")
- Offer free shipping

### "My ads aren't working!"
**Solutions:**
- Try different targeting
- Improve ad creative (better video/image)
- Test different products
- Lower price point
- Better ad copy (use templates)

### "Customer wants refund!"
**Solutions:**
- Offer partial refund (10-20%)
- Offer replacement instead
- Ask them to wait longer for shipping
- Only full refund as last resort
- Use as learning experience
