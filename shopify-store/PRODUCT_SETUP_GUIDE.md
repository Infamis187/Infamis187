# Shopify Product Setup Guide - Start Making Money!

## Step-by-Step: Adding Products to Your Shopify Store

### 1. Log into Your Shopify Admin
- Go to: `https://[your-store-name].myshopify.com/admin`
- Enter your login credentials

### 2. Navigate to Products
- Click on **"Products"** in the left sidebar
- Click **"Add product"** button (top right)

### 3. Fill Out Product Information

#### Product Title
- Use descriptive, keyword-rich titles
- Example: "Wireless Bluetooth Headphones - Noise Cancelling, 30Hr Battery"
- Keep it under 70 characters for best SEO

#### Product Description (SEO-Optimized)
**Format your description like this:**

```
[Opening Hook - What problem does it solve?]

Key Features:
• Feature 1 with benefit
• Feature 2 with benefit
• Feature 3 with benefit
• Feature 4 with benefit

[Detailed description paragraph explaining the product]

Specifications:
- Material: [details]
- Dimensions: [details]
- Weight: [details]
- Colors available: [list]

Perfect For:
✓ Use case 1
✓ Use case 2
✓ Use case 3

What's Included:
- Item 1
- Item 2
- Warranty/guarantee info

[Call to action - why buy now?]
```

### 4. Upload High-Quality Images

**Image Requirements:**
- **Format:** JPG or PNG
- **Size:** 2048 x 2048 pixels (minimum)
- **Aspect Ratio:** Square (1:1) or 4:5 works best
- **File Size:** Under 4MB each
- **Quantity:** 5-8 images per product

**Image Checklist:**
1. Main product image (white background)
2. Product from different angles
3. Product in use / lifestyle shot
4. Close-up of key features
5. Size/scale reference
6. Product packaging (optional)

**Image Optimization:**
- Rename files with keywords: `blue-wireless-headphones-front.jpg`
- Add ALT text for SEO: "Blue wireless noise-cancelling headphones"
- Compress images before uploading (use TinyPNG.com)

### 5. Set Pricing

**Regular Price Strategy:**
- Research competitor pricing
- Consider your costs + desired profit margin
- Use psychological pricing: $29.99 instead of $30.00

**Compare at Price (Optional):**
- Show original price if running a sale
- Creates urgency: Was $49.99, Now $29.99

### 6. Inventory & Variants

**Inventory:**
- Track quantity: Yes (recommended)
- Set stock level
- Enable "Continue selling when out of stock" if dropshipping

**Variants (if applicable):**
- Size: Small, Medium, Large, XL
- Color: Black, White, Blue, Red
- Material: Cotton, Polyester, etc.

### 7. SEO Settings (CRITICAL!)

Click **"Edit website SEO"** at the bottom:

**Page Title:**
- 50-60 characters
- Include main keyword
- Example: "Premium Wireless Headphones | 30Hr Battery | Free Shipping"

**Meta Description:**
- 150-160 characters
- Compelling, includes keywords
- Example: "Experience crystal-clear sound with our wireless Bluetooth headphones. 30-hour battery, noise cancellation, and comfortable fit. Order now with free shipping!"

**URL Handle:**
- Keep it short and descriptive
- Use hyphens, not underscores
- Example: `premium-wireless-headphones-30hr-battery`

### 8. Product Organization

**Product Type:**
- Example: "Electronics", "Clothing", "Home & Garden"
- Helps with organization and filtering

**Vendor:**
- Your brand name or supplier

**Collections:**
- Add to relevant collections: "Best Sellers", "New Arrivals", "Sale Items"

**Tags:**
- Use 5-10 relevant tags
- Example: wireless, bluetooth, headphones, audio, music, tech, gift

### 9. Shipping

**Weight:**
- Enter accurate weight for shipping calculations

**Customs Information:**
- Required for international shipping
- Country of origin
- HS tariff code (if applicable)

### 10. Product Availability

**Sales Channels:**
- ✓ Online Store
- ✓ Facebook & Instagram (if set up)
- ✓ Buy Button

**Status:**
- **Active:** Product is live and visible
- **Draft:** Save for later

## SEO Best Practices

### Keywords to Include:
1. **Primary keyword:** Main product name (use 2-3 times)
2. **Secondary keywords:** Benefits, features, use cases
3. **Long-tail keywords:** Specific phrases people search for

### Writing Tips:
- Write for humans first, search engines second
- Use natural language, don't stuff keywords
- Answer common questions in description
- Include measurements, materials, care instructions
- Add social proof: "Best seller", "Customer favorite"

### Conversion Optimization:
- Use bullet points for scannability
- Highlight benefits, not just features
- Create urgency: "Limited stock", "Sale ends soon"
- Offer guarantees: "30-day money back", "Free returns"
- Include shipping info: "Free shipping over $50"
