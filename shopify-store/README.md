# Infamis187 Shopify Store

Your custom Shopify theme for making money online!

## Directory Structure

```
shopify-store/
├── assets/          # CSS, JS, images, and other static files
│   ├── theme.css
│   └── theme.js
├── config/          # Theme configuration files
│   ├── settings_schema.json
│   └── settings_data.json
├── layout/          # Theme layout files
│   └── theme.liquid
├── locales/         # Translation files
├── sections/        # Reusable sections
├── snippets/        # Reusable code snippets
└── templates/       # Page templates
    ├── index.liquid
    ├── product.liquid
    └── collection.liquid
```

## Features

- Modern, responsive design
- Product grid layout
- Shopping cart functionality
- Mobile-friendly navigation
- Gradient hero section
- Easy to customize

## Installation

1. Zip the `shopify-store` folder
2. Go to your Shopify admin panel
3. Navigate to Online Store > Themes
4. Click "Upload theme"
5. Upload the zip file

## Customization

Edit the CSS in `assets/theme.css` to change colors, fonts, and layout.
Modify templates in the `templates/` folder to change page structure.
